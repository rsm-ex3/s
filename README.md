# Sebez Cafe & Restaurant website

A responsive white, cream and warm-brown cafe website inspired by the supplied UI reference.

## Included
- Home hero, menu filters/search, About, Gallery, Reservations, Contact and footer
- Brown-tinted version of the supplied Sebez logo
- Food item names and prices limited to clearly readable English items from the supplied menu photos
- Online illustrative food photography, with a visible disclosure that photos may differ from the cafe's actual servings
- Responsive mobile navigation

## Not connected yet
- Reservation form is a front-end preview only; it does not send a reservation to the cafe.
- There is no payment integration.
- There is no admin dashboard.
- Contact details and opening hours are intentionally left for the cafe to confirm rather than inventing them.

## Run locally
Open `index.html` in a browser, or serve this folder with any static web server.

## Before publishing
1. Confirm every menu item and price against the latest physical menu.
2. Replace illustrative photos with the cafe's own photos if available, or keep the disclosure visible.
3. Add the cafe's verified address, phone number and opening hours.
4. Connect the reservation form to a real inbox or backend if online reservations are required.
